⚙ How the System Works

A seamless integration connecting NoSQL document storage, machine learning preprocessing pipelines, and a web application interface.

1
MongoDB Storage
Raw training records (customers_train) and testing records (customers_test) are maintained as NoSQL documents in customerChurnDB.
2
Data Extraction
PyMongo queries the database, projects out internal _id fields, and converts document streams into high-performance Pandas DataFrames.
3
Pipeline Preprocessing
Scikit-learn ColumnTransformer standardizes numerical features (z-score) and encodes categorical fields (One-Hot), preventing data leakage.
4
Logistic Regression
The classification model learns optimal decision boundaries, outputting both binary decisions and well-calibrated class probabilities.
5
Result Persistence
Every prediction generated via the web UI is logged with a UTC timestamp and full input metadata into MongoDB's churn_predictions collection.
